# FLUX.1-schnell

### Ultra-fast image generation model by Black Forest Labs

FLUX.1-schnell is the fastest model in the FLUX family — generating stunning, photorealistic images in just 1-4 steps. Optimized for speed without sacrificing quality, it's ideal for rapid prototyping and real-time generation.

<br>

---

## Features

| | |
|:---|:---|
| **1-4 Step Generation** | Produces high-quality outputs with dramatically fewer inference steps |
| **Photorealistic Output** | Exceptional prompt adherence and fine detail in generated images |
| **Open Weights** | Freely available for personal and commercial use under Apache 2.0 |
| **GGUF Compatible** | Runs on consumer hardware via llama.cpp and ComfyUI backends |
